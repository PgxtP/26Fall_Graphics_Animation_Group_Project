# 第 2 章 虚拟示教器交互架构与安全控制流

负责角色：2 号位（组员 A）。验证日期：2026-10-23。

本章对应六关节示教交互、界面角度与内部弧度换算、关节限位、使能/失能/急停安全状态机、速度倍率、TCP 位姿显示及主场景联调。实现文件为 `src/ui/TeachingBox.js`、`src/ui/teachingBox.css`，由 `src/main.js` 完成总装。

## 2.1 设计目标与模块边界

示教器只负责读取用户操作、显示控制状态和输出标准化数据，不重新加载模型、不创建场景、相机、渲染器或动画循环，也不实现运动学算法。主程序和示教器之间的数据流为：

~~~text
滑块或数值输入（°）
        ↓ 角度转弧度、逐关节限位
TeachingBox.onJointChange([j1, ..., j6])
        ↓
main.js / applyAngles()
        ↓ 安全状态检查
RobotModel.setJointAngles() → 机械臂模型
        ↓
实际关节值与 TCP 位姿
        ↓
syncSliders() / updateTCPDisplay()
~~~

所有模块间关节数据统一为 `[j1, j2, j3, j4, j5, j6]`，单位为弧度；只有示教器显示层使用角度。TCP 位置沿用工程米制，RPY 面向用户显示为角度，四元数按 `xyzw` 顺序显示。

## 2.2 六关节交互与限位

构造函数接收六组 `{ min, max }` 弧度限位，先验证数量、有限性及上下限顺序，再复制保存，避免外部修改原数组影响 UI。没有使用统一的 ±180° 常量。当前模型的实际界面范围为：

| 关节 | 下限 | 上限 |
| --- | ---: | ---: |
| J1 | -180° | 180° |
| J2 | -120° | 120° |
| J3 | -120° | 120° |
| J4 | -180° | 180° |
| J5 | -120° | 120° |
| J6 | -180° | 180° |

每个关节包含一个滑块和一个 `number` 数值输入框，步长为 0.1°。两类输入共用同一更新函数，因此滑块、数值框和内部状态始终一致。输入值先在该关节自身角度边界内钳制：

\[
\theta_{deg}^{*}=\min(\theta_{max},\max(\theta_{min},\theta_{deg})).
\]

再转换为内部弧度，并再次用原始弧度边界保护：

\[
\theta_{rad}=\theta_{deg}^{*}\frac{\pi}{180},\qquad
\theta_{deg}=\theta_{rad}\frac{180}{\pi}.
\]

每次有效用户操作均发送完整六元素数组的独立副本，防止调用方修改示教器内部数组。实测在 J2 输入 500° 时，界面和回调均钳制到 120°（`2.0943951023931953 rad`）。

## 2.3 安全状态机

示教器定义三种状态：

| 状态 | 关节输入 | 普通使能按钮 | 运动处理 |
| --- | --- | --- | --- |
| `ENABLED` | 可用 | 显示“失能” | 允许手动关节控制 |
| `DISABLED` | 禁用 | 显示“使能” | 主程序拒绝关节指令并停止当前运动 |
| `ESTOP` | 禁用 | 禁用 | 立即停止当前运动并锁定 |

状态转换为：

~~~mermaid
stateDiagram-v2
  [*] --> ENABLED
  ENABLED --> DISABLED: 点击失能
  DISABLED --> ENABLED: 点击使能
  ENABLED --> ESTOP: 点击急停
  DISABLED --> ESTOP: 点击急停
  ESTOP --> DISABLED: 显式复位急停
~~~

急停不能直接转为使能。用户必须先点击“复位急停”，状态只恢复到 `DISABLED`，然后再次点击“使能”才能继续操作。`onStateChange()` 将状态通知主程序，主程序的 `setState()` 负责停止调试联动及 MOVJ 播放，并由 `applyAngles()` 统一拦截非使能状态下的运动指令。

主程序保留组长调试控件，因此增加无回调的状态同步，使两套显示使用同一状态。该同步只刷新 UI，不再次派发状态事件，不会形成递归。

## 2.4 速度倍率

倍率滑块范围为 10%～100%，步长为 10%，默认 100%。界面保存的比例为：

\[
r=\frac{p}{100},\qquad p\in[10,100],\quad r\in[0.1,1.0].
\]

`getSpeedRatio()` 返回浮点比例，供 MOVJ 播放器调用。例如界面显示 40% 时返回 `0.4`。倍率只提供给运动规划模块，不在示教器中自行建立第二套定时器或修改机械臂运动学。

## 2.5 TCP 位姿实时显示

主动画循环每帧调用 `robot.getTCPPose()`，并将结果传给 `updateTCPDisplay()`。HUD 显示：

- 世界位置 `X/Y/Z`：单位 m，保留 4 位小数；
- RPY：采用工程约定的 ZYX 表示，显示为角度并保留 2 位小数；
- 四元数：按 `(x,y,z,w)` 顺序显示，保留 4 位小数。

方法会验证 10 个位置/姿态分量均为有限数。若数据结构错误则抛出异常，由主循环捕获、停止运动并转入失能状态，避免错误数据静默传播。

## 2.6 自动运动时的滑块同步

`syncSliders(anglesRad)` 接收六关节弧度数组，逐项进行限位保护、换算成角度并刷新滑块和数值框。该方法不调用 `onJointChange()`，因此数据流为单向 UI 刷新，不会出现：

~~~text
自动运动 → syncSliders → onJointChange → applyAngles → syncSliders → ...
~~~

的递归循环。真实联调中，从组长调试滑块把 J3 设置到 45° 后，正式示教器同步显示 45°，机械臂 TCP 同时更新。

## 2.7 主程序正式接入

`main.js` 导入 `TeachingBox`，把面板挂载到已有三维视口，并传入 `robot.jointLimits`：

~~~javascript
const teachingBoxContainer = document.createElement('div');
teachingBoxContainer.id = 'teaching-box-container';
viewport.append(teachingBoxContainer);

const teachingBox = new TeachingBox(
  teachingBoxContainer,
  robot.jointLimits,
);
connectTeamModules({ teachingBox });
~~~

`connectTeamModules()` 完成关节回调和状态回调绑定，并用机器人当前实际关节值初始化面板。主循环继续由组长代码唯一持有，每帧更新 TCP；自动运动时只调用反向同步接口。

## 2.9 结论与后续接口

本章负责的六关节交互、角度/弧度换算、安全状态机、速度倍率、TCP HUD、外部同步和主场景接入均已实现并通过独立测试及真实浏览器联调。后续 MOVJ 模块只需在播放时读取 `getSpeedRatio()`，并继续由主循环把实际关节值传给 `syncSliders()`；示教器无需修改运动学、模型或渲染架构。
