## 二、关于报告提交与本地运行的常见问题（FAQ）

1. **需要每个人交一份完全不同的实验报告吗？**
   - 全组**共用同一套完整代码与联调实验数据**（确保满足讲义“a~d 四项全部完成”的验收要求），无需重做 5 套实验。
   - **若按小组交 1 份总报告**：每人写完上表中自己负责的 1 章，交由 5 号位拼装成完整报告，并在封面注明《小组成员分工表》。
   - **若平台要求每人分别上传个人报告**：全组共享完整实验图表与数据，每个人在个人报告中**详写自己负责章节的推导与代码实现**，其余章节简述，并在文末附上各自独立的《个人分工与实验心得总结》。

2. **每个人都必须在自己电脑上跑通 3D 场景吗？**
   - **开发阶段**：只有 **1 号位（组长）** 必须全程在本地跑完整的 3D 机械臂场景并负责总联调；2~5 号位负责的模块均已按 [`五人组接口与函数定义.md`](../作业文档与分工/2026-10-23_小组作业多人分工方案_01/五人组接口与函数定义.md) 解耦为独立 `.js` 文件，即使不跑 3D 模型也能独立编写和验证。
   - **本地一键运行（仅需 1 分钟）**：如果队友想在自己电脑上查看完整 3D 效果，只需安装 Node.js 后克隆本仓库并执行：
     ```powershell
     npm install
     npm run dev
     ```
     在浏览器打开终端显示的 `http://127.0.0.1:xxxx` 即可（**切勿直接双击打开 `index.html`**，否则会因 `file://` 协议触发 CORS 跨域拦截）。
