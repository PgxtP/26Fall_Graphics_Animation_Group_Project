npm run verify:leader

~~~

Node.js 使用 ^20.19.0 或 >=22.12.0，本次版本为 24.20.0。访问终端 HTTP 地址，不能双击 HTML。

页面含真实机械臂、六角度输入、归零、联动、急停、FK 验证和 JSON 导出。当前为组长调试入口，正式示教器可挂到单独 DOM 容器，接入后按需隐藏调试区。

## 稳定接口

~~~javascript
robot.setJointAngles([j1, j2, j3, j4, j5, j6]); // 弧度；返回实际钳制值
robot.getJointAngles();                       // 独立数组
robot.getTCPPose(toolOffset);                 // 世界位姿；省略 offset 为法兰
Kinematics.forwardKinematics(angles);         // 默认工位世界系法兰矩阵
Kinematics.verifyFK(angles, actualMatrix);    // 两项误差均 <1e-6 才通过
~~~

模型重新摆放后：

~~~javascript
const fk = new Kinematics(robot.getKinematicConfig());
const matrix = fk.forwardKinematics(robot.getJointAngles(), toolOffset);
~~~

长度按工程米制解释，尚未做真机标定。四元数输出 xyzw，RPY 为 ZYX 对应的 roll/pitch/yaw，弧度。轴在各自父系，默认末端是法兰原点。

## main.js 接入示例

模块完成后，由组长在 start() 内 window.robotApp 已建立之后添加以下调用。对应类需从各自源码导入，当前不自动运行未完成骨架。

~~~javascript
// 文件顶部导入 TeachingBox、Workstation、PoseManager、MOVJPlanner、TrajectoryCharts。
const container = document.createElement('div');
container.id = 'ui-container';
document.body.append(container);
const teachingBox = new TeachingBox(container, robot.jointLimits);
const workstation = Workstation.initWorkstation(scene);
const poseManager = new PoseManager();
const planner = new MOVJPlanner();
const charts = new TrajectoryCharts();

window.robotApp.connectTeamModules({
  teachingBox, workstation, poseManager, planner, charts,
});
~~~

scene 和 robot 复用现有对象，不再创建第二套 renderer 或动画循环。A 的 CSS 自行导入或由 main.js 显式导入一次。

### A：示教器

接入函数绑定 onJointChange 和 onStateChange；每帧调用 updateTCPDisplay，运动时调用 syncSliders。同步方法只更新 UI，不再次派发用户输入事件，以免递归。

状态为 ENABLED、DISABLED、ESTOP。急停不能被普通“使能”事件直接清除。本次调试面板支持显式复位，复位后保持失能，重新使能不恢复旧动作；A 的正式复位控件需要统一事件契约。

顶层 window.robotApp.setJointAngles() 检查使能/急停；window.robotApp.robot 为底层开发对象，直接调用不经过主入口控制状态检查。

### B：工具与工位

~~~javascript
const offset = Calibration.createTCPOffset(
  new THREE.Vector3(0, 0, 0.2), // 沿法兰 Z 方向 0.2 m
  new THREE.Euler(0, 0, 0),     // 弧度
);
window.robotApp.setToolOffset(offset);
Workstation.attachWorkpiece(window.robotApp.flange, workstation.workpiece);
~~~

setToolOffset(undefined) 恢复法兰原点。偏置只能包含刚体平移旋转，不接受缩放/反射。预置 tcp 节点不会自动叠加。三点法和真实抓取判定仍由 B 完成。

### C：位姿与播放

~~~javascript
poseManager.savePose('P1', robot.getJointAngles());
planner.loadProgram(poseManager.getPoseList());
planner.play(teachingBox.getSpeedRatio(), false);
~~~

上面调用由 A/C 的正式“记录”“运行”按钮触发。主循环负责 update(dt) 和模型同步，dt 单位为秒；isMoving=false 的最后一帧也会写入。急停、失能或手动点动中止程序，恢复后需要用户重新启动。联动调试按钮不替代 MOVJ。

### D：点云与采样

~~~javascript
const cloud = WorkspaceCloud.generatePointCloud(
  window.robotApp.fkPosition,
  robot.jointLimits,
  20000,
);
scene.add(cloud);
~~~

fkPosition 输入六弧度角，返回世界系米制位置，包含当前工具偏置，不修改模型。改变工具后重新生成点云。

charts.recordSample(t, position, velocity) 获得秒、米和米/秒。速度用相邻采样位置差除以实际间隔；首样本为 0。采样在渲染帧累计，间隔至少 20 ms，不保证严格 50 Hz。也可能包含静止阶段，D 可在程序起止时清空或截取一次动作区间。
