# 五人组各模块接口契约与函数定义规范

- **文档目的**：明确 5 位组员的模块职责、代码输入输出（I/O）与关键函数签名，确保所有人并行编写代码时不冲突、接口能直接对接。
- **技术约定**：
  - 空间坐标系：Three.js 右手系（$X$ 轴向右红、$Y$ 轴向上绿、$Z$ 轴向外蓝）。
  - 单位约定：**代码内部计算一律使用 米（m） 与 弧度（rad）**；仅在给用户看界面时换算为 毫米（mm） 与 角度（$^\circ$）。
  - 关节数据格式：固定为 6 元素数组 `[j1, j2, j3, j4, j5, j6]`（单位：弧度）。

const charts = new TrajectoryCharts();

  requestAnimationFrame(animate);

  const dt = (now - lastTime) / 1000;

    const tcpPose = robot.getTCPPose();
    charts.recordSample(now / 1000, tcpPose.position, planner.currentVelocity);
