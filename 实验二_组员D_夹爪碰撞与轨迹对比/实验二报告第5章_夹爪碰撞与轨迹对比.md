## 5.3 夹爪碰撞检测

### 5.3.1 几何口径

- 把夹爪子树（`gripper` 组，或退回 `link_flange` / `tcp` 子树）的每个网格展开为**世界坐标三角面片**；障碍物同理。
- **粗筛**：夹爪与障碍物的 AABB（按安全间距外扩）不相交则跳过，绝大多数帧只付一次包围盒比较。
- **穿透判定**：三角形—三角形相交（Möller 算法，两三角形各自跨越对方平面且交线段在公共直线上重叠）。
- **包含判定**：夹爪 AABB 完全落在障碍物 AABB 内（或反之）时，三角面片并不相交，必须单独判为穿透。这是在实现阶段发现并补上的一类真实漏检。
- **间距**：顶点到三角面片最近距离的近似（双向取最小），用于安全间距 `margin`。`margin = 0` 时只拦穿透，`margin > 0` 时把"贴近但未穿透"也拦下。
- **缓存与上限**：三角面片按"网格 + 世界矩阵 + 几何 uuid"缓存，静态台面只算一次；单障碍物参与检测的三角面对数受 `maxPairs` 限制，超出时按步长抽样并保留粗筛结论。

### 5.3.2 与运动层合并

`isColliding()` 在原有 4 段检查之后增加第 5 段夹爪检测。命中时：

1. 本帧位移**回滚**到上一帧关节角（与底座原有回滚行为一致）；
2. `state.collision = true`；
3. 写入 `state.collisionReason`（可读原因）、`state.collisionDetail`（命中对、间距、三角面片数）、`state.collisionCount`（累计次数）。

`state` 新增的三个字段是**只增不改**的，原有 `state.collision` 语义不变，因此 `collision.test.mjs`、`program.test.mjs` 等既有测试无需改动即可通过。

### 5.3.3 接口

```js
import { checkGripperCollision, resolveGripperScene } from './js/pendant-motion.js';

const result = checkGripperCollision(
  [window.robotSimulation.workstation.gripper, window.robotSimulation.workstation.workpiece],
  [{ object: window.robotSimulation.workstation.table, name: '工作台' }],
  { margin: 0.01, probeDistance: 0.05 },
);
// result: { colliding, margin, hits[], minDistance, gripperTriangles, obstacleTriangles, obstaclesChecked, reason }
```

`createMotion(api, urdfModel, options)` 的第四个参数为可选项，支持 `{ gripperCollision: false, gripperMargin: 0.02, extraObstacles: [...], maxPairs }`；两参数调用保持原行为。运动实例另外暴露只读的 `checkGripperCollision(parts?, obstacles?, options?)` 与 `getGripperCollisionConfig()`，界面与测试都可以在不移动机械臂的前提下主动检测一次。

### 5.3.5 边界与限制

1. 不做连续碰撞检测（CCD），只在每个仿真步的末端位形检测；步长过大时可能"跨过"薄壁。
2. 间距是"顶点—三角面片"近似，不是严格的三角形—三角形最近距离，粗网格下可能偏大约一个面片尺度。
3. 不含自碰撞（夹爪左右指互撞）与柔性/摩擦；抓取成功与否仍由 `Workstation` 的抓取容差判定。
4. 未合入组员 B 的几何夹爪时，自动退回 `link_flange` 子树检测，此时只覆盖法兰及已挂载工件，不覆盖虚拟指形。

## 5.4 直线度偏差

对同一对起终点（弦长 **0.728** 资产单位）分别执行 MOVJ 与 MOVL，逐帧记录 TCP 世界坐标，计算每个采样点到"起点—终点"弦线的垂距。

**表 5-3　直线度偏差统计**

| 指标 | MOVJ | MOVL |
| --- | --- | --- |
| 采样帧 / 插补点 | 45 帧（60 Hz） | 16 个插补点 |
| 运动时长 | 0.733 s | 2.427 s |
| 最大偏差 | **0.037786** | **0.000884** |
| 平均偏差 | 0.019428 | 0.000555 |
| RMS 偏差 | 0.023552 | 0.000609 |
| 偏差 / 弦长 | **5.19 %** | **0.12 %** |
| 轨迹长度 | 0.732133 | 0.727736 |
| 迂回系数（路径 / 弦长） | 1.0057 | 0.9997 |

- **图 5-1**：`第五章_图/图5-1_直线度偏差.png`。MOVJ 的偏差呈单峰抛物线（关节空间等速插值在笛卡尔空间走圆弧），MOVL 的偏差被压在 1e-3 量级，且不再随行程单调增长，而是围绕逆解位置容差（`posTol = 1e-3`）抖动。
- MOVL 的 0.000884 与规划器报告的 `maxPosError = 9.14e-4` 同量级，说明剩余偏差主要来自逐点逆解的位置容差，而不是插补方式。
- MOVL 的迂回系数略小于 1（0.9997），是"相邻插补点直线距离之和"小于弦长的离散化假象，不作为平滑性指标。

## 5.5 各轴角速度

由相邻采样帧的关节角差商得到：`ω_i(t_k) = (θ_i(t_k) − θ_i(t_k−1)) / (t_k − t_k−1)`，采样断档（dt ≤ 1e-6）时记 0，避免把帧抖动放大成尖峰。

**表 5-4　关节角速度统计（度/秒）**

| 关节 | MOVJ 峰值 | MOVL 峰值 |
| --- | --- | --- |
| J1 | 0 | 0 |
| J2 | 30.0 | 11.9 |
| J3 | 30.0 | 25.8 |
| J4 | 20.0 | 14.4 |
| J5 | 0 | 0 |
| 全段峰值 | **30.0** | **25.8** |
| 全段平均 | 10.89 | 4.01 |

- **图 5-2**：`第五章_图/图5-2_各轴角速度.png`（横轴为各自运动段的归一化进度，便于直接对比）。
- MOVJ 的角速度是标准 smoothstep 单峰：0 → 30 → 0，峰谷平滑，段内没有台阶。这正是 `pendant-motion.js` 用 `t²(3−2t)` 混合的直接结果。
- MOVL 的角速度由逆解点列差分得到，峰值 25.8°/s 小于 MOVJ 的 30°/s（说明这条直线段没有触发关节限速），但曲线呈分段折线：关节角不是时间的解析函数，而是"每段到位后再下发下一段"，段间存在速度台阶。
- 若报告需要"连续不停顿"的直线效果，应把 MOVL 的点列改成时间参数化的一次性插值，而不是逐段 `moveJ`；这一点与第 4 章的说明一致。

## 5.6 奇异区 DLS 阻尼

MOVL 规划结果的每个插补点都带 `dampingUsed`、`manipulability`、`singular`。把归一化行程 `s` 与 `λ` 画出来后，得到两个结构性结论。

**表 5-5　两种雅可比口径下的阻尼**

| 口径 | 雅可比形状 | 可操作度 w | 自适应阻尼 λ | 奇异标记 |
| --- | --- | --- | --- | --- |
| 带姿态约束（MOVL 逐点逆解） | 6×5 | 恒为 0 | 恒为上限 0.15 | 16/16 |
| 仅位置（`targetRot = null`，点动用） | 3×5 | 0.094 ~ 0.302 | 恒为下限 0.005 | 0/16 |
| 工作空间压力测试（位置） | 3×5 | 0.145 → 0.054 | 恒为下限 0.005 | 0/11 |

- **图 5-3**：`第五章_图/图5-3_DLS阻尼曲线.png`。左图为求解器里的阻尼律 `λ(w)`：`w ≥ 阈值(1e-3)` 时 λ = 0.005，否则按 `λ = √(min² + (max²−min²)·(1−w/阈值)²)` 平滑抬到 0.15。右图为同一条直线上的 λ(s)。
- **结论 1（真实缺陷）**：带姿态约束时雅可比是 6×5，`J·Jᵀ` 为 6×6 且秩最多 5，行列式**结构性为 0**，于是 `w ≡ 0`、`singular` 恒为真、λ 恒为上限。这条"奇异"标记反映的是矩阵形状，而非真实位形。
- **结论 2**：仅位置（3×5）时 `w` 在 0.09~0.30 之间，远高于 1e-3 阈值；把目标推到工作空间边界（压力测试，`posError` 从 0.022 涨到 0.400 仍不收敛）时 `w` 也只降到 0.054。也就是说，在这台五轴臂上"阻尼中间过渡段"实际上没有出现：要么恒为上限，要么恒为下限。
- **建议（供组长评估）**：把 `js/ik-solver.js` 的可操作度改成 `√det(JᵀJ)`（5×5，秩不亏）或在 `J·Jᵀ` 上加 `εI` 后再取行列式，奇异标记才具有区分度；本章的图表与数据是按"当前实现的真实行为"给出的，没有替它掩盖这一点。

## 5.7 轨迹形态对比

- **图 5-4**：`第五章_图/图5-4_轨迹对比.png`（该段 X 恒定，取 Y–Z 投影并平移到起点）。
- MOVJ 走出一条明显的弧线，最大偏离弦线 5.19%；MOVL 与起终点连线几乎重合，肉眼不可分辨。
- 结论：`MOVJ` 适合"不关心路径、只关心到位"的搬运，`MOVL` 适合"沿工作面走直线"的工序；两者的差别不在速度，而在路径是否受控。
