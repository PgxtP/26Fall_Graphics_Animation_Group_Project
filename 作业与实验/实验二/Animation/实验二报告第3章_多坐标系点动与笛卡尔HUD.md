# 第 3 章 多坐标系点动与笛卡尔 HUD

## 3.1 任务目标

本章在实验一关节点动示教器的基础上增加 Joint、Base、Tool、User 四种点动模式，并通过组长提供的逆运动学接口实现 TCP 在 X、Y、Z 三个方向上的小步长移动。界面同时显示当前模式下 TCP 的 X/Y/Z 位置和 R/P/Y 姿态。发生未使能、急停、用户坐标系未建立、逆解不收敛、奇异位形或关节角超限时，系统拒绝下发运动。

实验二底座为五轴机械臂。笛卡尔面板只提供 ±X、±Y、±Z 位置微调按钮，因此调用 IK 时使用 `targetRot = null` 的仅位置三维逆解。R/P/Y 用于实时显示，不增加实验要求之外的姿态点动功能。

## 3.2 总体设计

示教器的多坐标系点动流程如下：

1. 操作者选择 Joint、Base、Tool 或 User 模式。
2. Base、Tool、User 模式根据当前坐标系计算所选轴在世界坐标中的方向。
3. 在当前 TCP 世界位置上叠加一个带正负号的步长，得到目标位置。
4. 将目标位置、当前五关节角和 `{ method: "auto" }` 传给组长的 `solveIK()`。
5. 检查 IK 的收敛状态、奇异标记、关节角数量、有限性和限位。
6. 检查通过后，将五关节弧度数组交给原有 `moveJ()`。运动过程继续使用组长底座已有的速度倍率、急停和碰撞保护。

界面由 `js/joint-controls.js` 动态创建，没有修改 `index.html`。这样既保持了组员 A 的文件边界，也可以直接接入组长已有的 `bindJointControls()` 初始化流程。

## 3.3 四种点动模式

### 3.3.1 Joint 模式

Joint 模式沿用实验一的五关节按钮、滑块和角度输入框，不调用笛卡尔 IK。此时笛卡尔按钮被禁用，HUD 使用 Base 坐标显示 TCP 位姿。

### 3.3.2 Base 模式

Base 模式从场景树读取 `link_base.matrixWorld`。设局部单位轴为 \(\mathbf e_a\)，基座旋转矩阵为 \(R_b\)，点动步长为 \(s\)，则世界坐标增量为：

\[
\Delta \mathbf p_w = R_b\mathbf e_a s
\]

### 3.3.3 Tool 模式

Tool 模式使用当前 `tcp.matrixWorld` 的旋转部分，把工具局部轴转换到世界坐标。工具坐标系随 TCP 姿态变化，因此同一个 +X 按钮在机械臂姿态改变后可能对应不同的世界方向。

### 3.3.4 User 模式

User 模式复用组员 B 提供的 `api.calibration.userMatrix`。该矩阵表示世界坐标到用户坐标的变换，因此计算点动方向时先求逆，得到用户坐标到世界坐标的旋转关系：

\[
\Delta \mathbf p_w = R_u\mathbf e_a s
\]

如果尚未建立用户坐标系，User HUD 显示不可用状态，位置点动按钮立即禁用。

三种笛卡尔模式的目标位置统一表示为：

\[
\mathbf p_{target}=\mathbf p_{tcp}+\Delta\mathbf p_w
\]

## 3.4 IK 接入与安全拦截

点动函数使用当前五关节角作为 IK 初值，使求解器优先返回邻近当前位形的解。调用形式为：

```js
const result = api.solveIK(
  targetPosition,
  null,
  currentJoints,
  { method: 'auto' },
);
```

下列任一条件成立时，程序抛出报警并停止下发：

- 机械臂未使能或急停处于锁定状态；
- 当前正在执行程序运动；
- 点动轴或步长无效；
- User 模式下尚未建立用户坐标系；
- IK 返回 `converged === false`；
- IK 返回 `singular === true`；
- IK 结果不是五个有限关节角；
- 任一关节角超出底座提供的实际限位。

合法结果交给原有 `moveJ(angles)`，因此不会绕开底座已有的速度控制、使能/急停状态和逐帧碰撞回退。切换点动模式时也会停止当前手动运动，避免两个控制模式同时生效。

## 3.5 笛卡尔面板与 HUD

面板包含以下内容：

- Joint、Base、Tool、User 坐标形式选择框；
- X/Y/Z/R/P/Y 六个位姿显示框；
- 可配置的位置点动步长，单位沿用模型资产单位；
- −X/+X、−Y/+Y、−Z/+Z 六个微调按钮；
- 普通状态和红色报警状态提示。

HUD 每帧读取 TCP 世界矩阵，并换算为当前模式的相对矩阵。Base 模式显示 TCP 相对基座的位姿；User 模式显示 TCP 相对用户坐标系的位姿；Tool 模式以当前 TCP 自身为参考，因此相对位置和姿态均为零。RPY 使用与底座一致的 ZYX 固定轴约定，界面角度单位为度。

位置点动步长默认值为 0.05，操作者可以修改。该值仅代表模型资产单位，工程没有把模型长度标定为米，因此界面和报告均不将其写成毫米或米。

## 3.6 独立测试设计

独立测试文件为 `js/tests/jog-mode.test.mjs`，不依赖浏览器 DOM，覆盖以下内容：

1. 四种模式切换和非法模式拒绝；
2. Joint 模式拒绝笛卡尔点动；
3. Base 轴向转换及完整五关节数组下发；
4. Tool 轴向随 TCP 姿态变化；
5. 控制器创建后调用组长挂载的正式 `api.solveIK`；
6. User 模式使用世界到用户矩阵的逆变换；
7. Base、Tool、User HUD 相对位姿换算；
8. 未标定、未使能、非法轴和非法步长拦截；
9. IK 未收敛、奇异、返回格式错误和关节超限拦截。

此外使用完整页面进行了无头 Chrome 联调，检查动态面板生成、六个 HUD 字段、六个点动按钮、模式切换、User 未标定禁用、用户坐标系建立后的恢复、急停禁用及真实 IK 调用。

## 3.7 测试结果

| 测试项目 | 结果 |
| --- | --- |
| `jog-mode.test.mjs` 独立测试 | 9/9 通过 |
| 标定、碰撞、IK、点动、程序运动回归测试 | 18/18 通过 |
| JavaScript 语法检查 | 通过 |
| 完整页面面板生成 | 1 个面板、6 个位姿字段、6 个方向按钮，检查通过 |
| Base +X 真实点动 | 步长 0.005 模型单位，DLS IK 成功下发 |
| Tool HUD | X/Y/Z/R/P/Y 均为 0，符合 TCP 相对自身的定义 |
| User 未标定保护 | HUD 不可用且按钮禁用 |
| User 建系后恢复 | HUD 恢复数值，按钮恢复可用 |
| 急停保护 | 按钮立即禁用并显示报警 |

测试表明，多坐标系方向换算、IK 调用和安全拦截均按照接口契约工作，且没有破坏底座原有的标定、碰撞、IK 和程序运动测试。
